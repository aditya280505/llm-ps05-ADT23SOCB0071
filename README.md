# AI-Powered Social Media Caption Generator

## Project Overview

The Social Media Caption Generator is an AI-powered
application that generates engaging social media captions
and relevant hashtags using Google Gemini.

It helps content creators, students and businesses save
time while creating content for different social media
platforms.

## Features

- Generate 3 unique captions.
- Supports Instagram, LinkedIn and X (Twitter).
- Platform-specific writing styles.
- Relevant hashtag generation.
- Gemini AI integration.
- Download generated captions.
- Interactive Streamlit interface.

## Technology Stack

- Python
- Streamlit
- Google Gemini 2.5 Flash
- Google Gen AI SDK
- Prompt Engineering

## Installation

1. Clone the repository.

2. Install dependencies:

   pip install -r requirements.txt

3. Create a .env file.

4. Add your Gemini API key:

   GEMINI_API_KEY=your_api_key

5. Run the application:

   streamlit run app.py

## How It Works

1. Enter a short description of your social media post.
2. Select Instagram, LinkedIn or X.
3. Click Generate Captions.
4. The Gemini model generates three captions.
5. View and download captions with relevant hashtags.
